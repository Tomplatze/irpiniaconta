# Manrope font assets

The public UI uses self-hosted Manrope variable WOFF2 files (normal, weights 400–800). Latin and Latin Extended subsets cover the Italian interface. The font files total 39,816 bytes. No runtime requests to Google Fonts are required.

Retrieved on 2026-10-21 from the URLs returned by the official Google Fonts CSS endpoint:

- `https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap`
- Latin: `https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSvfedN4.woff2`
- Latin Extended: `https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggmxSvfedN62Zw.woff2`
- Licence: `https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt`

The original SIL Open Font License is retained in `OFL-Manrope.txt`.
